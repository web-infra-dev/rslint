# Rust + JS 迁移与 rsbuild 验收进度

**当前没有可接受的 rsbuild 性能收益结论。** 新架构已实现直接 Rust lint 路径，但完整工作量尚不能运行；不能把拒绝请求的耗时、旧 Go/Rust 过渡版或两规则 PoC 的约 46% 收益作为本次结果。完整迁移目标仍进行中，这份交付是 draft。

## 架构与完成范围

Rust 核心直接持有 tsrs 项目、AST 和 checker，25 条规则在 Rust 中执行，通过现有 N-API addon 与 JS 交换输入和诊断。新路径不复制整棵 AST 到另一个规则进程，也不启动或回退 Go。编译器是官方未修改的固定 commit，不需要本机未提交补丁。

已实现 21 条语法/控制流/绑定规则和 4 条类型规则，包括跨文件枚举比较、混合枚举、getter/setter 可赋值性以及不安全一元负号。目标清单核实为 **813 条规则、77 条声明需要类型信息、14 个功能面**；旧 812 条清单漏了 `import/no-webpack-loader-syntax`。完整原测试矩阵仍未验收。

默认 CLI/API、配置发现与作用域、ignore、完整自动修复与建议应用、插件、LSP、浏览器 WASM 和其余规则尚未迁移。新 JS 入口是显式文件的实验源码入口，未替换公开默认入口。仓库仍保留未迁移的原 Go 实现，**最终“源码、构建、产品均无 Go”的硬条件尚未满足**。

## 已验证与待验证

在独立草稿快照中使用未修改的 tsrs pin，限定两个构建任务并持有共享机器锁，验证以下范围。命令、源码/产物哈希与结果见 [`validation.json`](validation.json)，诊断原始对照见 [`oracle.json`](oracle.json)。

- Rust 核心 60 个测试通过；包含跨文件类型、联合/交叉类型、泛型访问器、完整诊断、UTF-16/BOM 位置及错误拒绝。
- 沿用 native crate 27 个解析/传输单元测试的通过证据（相关实现未变）；直接 addon 4 个测试通过，另在禁止子进程且 PATH 不含工具链的条件下验证直接运行。
- JS 实验入口 8 个真实 addon 集成测试、2 个返回值契约测试通过；显式配置、静默文件、规则 options、项目输入与拒绝不支持能力均有断言。
- 25 条规则在同一 9 文件 fixture 中均有正向命中，完整消息、位置、severity、文件集合与冻结原版一致，并保留无诊断文件。该对照包含两条 non-null 规则的完整 fix/suggestion payload；不代表完整上游规则矩阵或迭代自动修复验收。
- 受影响 Rust crates 的 clippy（包含所有 targets/features，warnings 视为错误）、格式与必要拼写检查记录在验证文件。

审查发现的 JS 语法错误遗漏已修复：改用 tsrs 的完整项目语法诊断接口，避免把 JS 中的 TS 类型标注错误当成成功 lint。另修复 BOM 的 JS 位置换算。旧基线对照脚本漏声明原生 TypeScript 插件的问题也已修正，最终对照要求全部启用规则实际产生正向命中。

未验证：全 813 规则及全部历史 fixtures、完整配置/插件/fix/LSP/WASM 入口、其他平台发布包、最终无 Go 净树/净构建、真实 rsbuild 完整候选诊断及性能 A/B。没有删除规则、降低原断言或用减少工作量的测试替代这些门禁。

复跑命令与后续验收条件见 [迁移指南](README.md)。完成 draft PR 不代表完整目标完成。
