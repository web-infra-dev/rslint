# Release information

Each new Rslint release records the full commit SHA of its embedded TypeScript
compiler. When that commit exactly matches an upstream release tag, its release
version is recorded too. Otherwise, `releaseVersion` is `null`.

Query an installed build without loading a project or config:

```sh
rslint --version
rslint --version --json
```

The same metadata is available from JavaScript:

```js
import { buildInfo } from '@rslint/core/build-info';

console.log(buildInfo.typescript.commit);
console.log(buildInfo.typescript.releaseVersion);
```

Development builds use `unreleased`. Older releases have no recorded compiler
binding. New rule counts refer to the first stable release supporting a rule;
canary builds do not change the version badges on rule pages.
