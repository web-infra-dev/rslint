# Bundled TypeScript Versions

TypeScript releases and commits bundled with each Rslint version.

<TypeScriptVersions />

A TypeScript release is shown only when its tag points to the exact recorded
commit. Other revisions are identified by their commit hash.

Tracking starts on **main**. Releases through **v0.9.1** are not included.

Rslint's Go compiler dependency moved from the archived
[microsoft/typescript-go](https://github.com/microsoft/typescript-go) staging
repository to [microsoft/TypeScript](https://github.com/microsoft/TypeScript),
where Microsoft now develops the Go port.
