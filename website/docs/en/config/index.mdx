# Configuration overview

This page lists Rslint's user-facing configuration options. Rslint uses an ESLint-style flat config: the configuration exports an array, and later matching entries override earlier ones.

See [Configuration File](/config/configuration-file) to create a config, understand config discovery, and learn how entries are merged.
